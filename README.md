# Tira E-Commerce Order Management System

## Software Requirements Specification (SRS)

### Project Overview
This repository contains the Software Requirements Specification (SRS) document for the **Tira E-Commerce Order Management System**. The document analyzes the business requirements of Tira's order management process and defines the functional and non-functional requirements of the system.

### Contents
- Introduction
- Purpose
- Scope
- Functional Requirements
- Non-Functional Requirements
- Conclusion

### Tools Used
- Microsoft Word
- GitHub

### Repository Purpose
This repository was created as part of an academic assignment to study and document the requirements of an e-commerce order management system.
